# Manual de usuario — Supermercado Yahweh

## Inicio de sesión
Ingrese usuario y contraseña. Un usuario activo con credenciales válidas accede al panel principal.

## Panel principal
Permite visualizar cantidades generales de productos, categorías, movimientos y productos con bajo stock.

## Productos
El administrador puede registrar, editar y eliminar productos. Cada producto contiene código, nombre, categoría, precios, cantidad, stock mínimo y fecha de vencimiento.

## Categorías
El administrador puede crear, editar y eliminar categorías.

## Movimientos
Seleccione producto, tipo de movimiento y cantidad. Las entradas incrementan el stock y las salidas lo disminuyen. El sistema rechaza cantidades no válidas y evita que el stock quede negativo.

## Reportes
El módulo de reportes muestra el inventario, productos con bajo stock y valor estimado. El botón de impresión permite imprimir o seleccionar la opción del navegador para guardar en PDF.

## Usuarios
La administración de usuarios está restringida al rol administrador. Se pueden crear usuarios con rol y estado.

## Regresar
Las vistas internas muestran el botón `← Regresar al panel principal`.

## Usuarios de demostración
- Administrador: `admin` / `admin123`
- Empleado: `empleado` / `empleado123`

Se recomienda cambiar estas credenciales en cualquier entorno diferente al académico/local.
